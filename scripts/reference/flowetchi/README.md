# Flowetchi reference (Flowertchi / Tamagotchi iD)

Flowetchi replaces **Violetchi** in Pet Village. Sprites are from the
**Flowertchi** Tamagotchi iD gallery (EN Violetchi is the same character line):

https://tamagotchi.fandom.com/wiki/Flowertchi/Sprite_Gallery

## Official gallery files

| Pose | Gallery file |
|------|----------------|
| neutral1 | `Violetchi id sprite.png` (iD gallery lead) |
| neutral2 | `IDFlowertchiNeutral2.png` |
| walk1 | `IDFlowertchiWalk.png` |
| walk2 | `IDFlowertchiWalk2.png` |
| happy | `IDFlowertchiHappy.png` |
| sad | `IDFlowertchiSad.png` |
| sleep | `IDFlowertchiSleep.png` |
| jump | `IDFlowertchiShock.png` (no Jump file) |

Regenerate:

```bash
npm run sprite:flowetchi
```
